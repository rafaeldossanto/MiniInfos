Privacidade.

Esta página apresenta o MiniInfos e direciona para o download do aplicativo no GitHub. Não há cadastro, formulário para enviar conversas, anúncios ou ferramentas de análise de visitas no código deste site.

Suas preferências de aparência e idioma

Ao escolher o modo claro ou escuro, o site salva essa escolha no armazenamento local do navegador, com a chave miniinfos.site.theme. A preferência fica no seu navegador e não é enviada a um servidor do MiniInfos. Se esse armazenamento estiver bloqueado, a troca continua funcionando durante a visita.

O idioma acompanha as preferências do navegador quando a opção Auto está selecionada. Se você escolher Português ou English, o site salva essa preferência com a chave miniinfos.site.language. Essa escolha também fica somente no navegador.

Links e downloads

Os links para o código, para os pacotes da comunidade e para o instalador abrem o GitHub. Ao acessar esses links, sua conexão passa pelo serviço correspondente, que tem suas próprias informações sobre privacidade. O provedor de hospedagem desta página também pode processar dados técnicos da conexão.

Ao chegar à área de downloads, o site consulta as releases públicas do GitHub para mostrar os pacotes disponíveis por sistema. Essa conexão segue a política de privacidade do GitHub.

Dados do aplicativo

Este site não recebe os registros dos chats do aplicativo. O MiniInfos lê os registros locais disponíveis. Consultas de limites dos provedores e verificações de atualizações são feitas pelos respectivos serviços, conforme descrito no repositório.
