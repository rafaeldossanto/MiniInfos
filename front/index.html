Algumas respostas.

O MiniInfos funciona em qual sistema?

O aplicativo é feito para Windows. O botão de download abre o instalador da última versão publicada no repositório do projeto.

O MiniInfos é uma IA ou gasta tokens?

Não. Ele acompanha os dados de uso dos aplicativos. O MiniInfos não conversa com modelos de IA nem gera consumo de tokens para mostrar os números.

Ele conta as conversas feitas no navegador?

As contagens de tokens vêm dos registros locais do Claude Code e do Codex. Elas não representam todas as conversas dos sites Claude ou ChatGPT. Os limites de uso da conta aparecem conforme os dados disponíveis em cada aplicativo.

Preciso colocar uma chave de API no site?

Não. Esta página só apresenta o MiniInfos e leva ao download. O aplicativo usa os registros locais e as integrações dos provedores no seu computador.

Os dados dos meus chats passam por este site?

Não. Esta página não recebe registros dos seus chats. No aplicativo, as contagens são lidas no computador; consultas de limites e atualizações são feitas pelos serviços correspondentes.

Posso adicionar meus próprios temas e mascotes?

Sim. As configurações permitem importar pacotes locais e escolher itens da comunidade. O guia do repositório explica como criar e compartilhar um pacote.
